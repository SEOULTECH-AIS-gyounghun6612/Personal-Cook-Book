# 수식 (Mathematics)

LaTeX의 가장 강력한 기능 중 하나임. 복잡한 수식을 미려하게 출력할 수 있음.

> `필수 패키지 (Preamble)`
>
> ```latex
> \usepackage{amsmath}   % 필수: align, equation* 등 수식 환경
> \usepackage{amssymb}   % 필수: \mathbb 등 특수 기호
> \usepackage{amsthm}    % 선택: 정리(Theorem), 증명(Proof) 환경
> ```

## 1. 수식 작성 모드

### 인라인 수식 (Inline)

문장 중간에 수식을 넣을 때 사용함.

* 사용법: `$ ... $` 또는 `\( ... \)`

> 예: 피타고라스 정리는 $a^2 + b^2 = c^2$이다.

### 독립 수식 (Display)

별도의 줄에 수식을 작성하고 강조할 때 사용함.

#### 번호 있는 수식 (`equation`)

중요한 수식으로, 나중에 참조(`\ref`)할 필요가 있을 때 사용.

```latex
\begin{equation}
    E = mc^2 \label{eq:energy}
\end{equation}
```

#### 번호 없는 수식 (`equation*` 또는 `[...]`)

단순한 전개 과정 등 번호가 필요 없을 때 사용.

```latex
\begin{equation*}
    f(x) = x^2 + 2x + 1
\end{equation*}
```

또는 간단히:

```latex
\[
    f(x) = x^2 + 2x + 1
\]
```

## 2. 여러 줄 수식 (`align`)

여러 줄의 수식을 등호(=) 기준으로 정렬할 때 유용함.

```latex
\begin{align}
    f(x) &= (x+1)(x-1) \\
         &= x^2 - 1
\end{align}
```

* 번호를 빼려면 `align*` 환경을 사용하면 됨.

## 3. 주요 기호 및 폰트 레퍼런스

### 1) 특수 폰트 (Special Alphabets)

집합, 벡터 등을 표기할 때 사용.

| 구분 | 명령어 | 예시 | 주요 용도 |
| :--- | :--- | :--- | :--- |
| **칠판 볼드체** | `\mathbb{R}` | $\mathbb{R}, \mathbb{N}, \mathbb{Z}$ | 실수, 자연수, 정수 집합 |
| **캘리그라피** | `\mathcal{L}` | $\mathcal{L}, \mathcal{D}, \mathcal{O}$ | 손실 함수, 데이터셋, 시간복잡도 |
| **볼드체** | `\mathbf{v}` | $\mathbf{v}, \mathbf{A}$ | 벡터, 행렬 |

### 2) 그리스 문자 (Greek Letters)

변수나 상수로 자주 쓰이는 문자들.

| 명령어 | 기호 | 의미 예시 |
| :--- | :--- | :--- |
| `\alpha`, `\beta`, `\gamma` | $\alpha, \beta, \gamma$ | 계수, 가중치, 학습률 |
| `\epsilon`, `\delta` | $\epsilon, \delta$ | 오차, 아주 작은 변화량 |
| `\theta`, `\phi` | $\theta, \phi$ | 각도, 모델 파라미터 |
| `\lambda` | $\lambda$ | 고유값(Eigenvalue), 규제 계수 |
| `\mu`, `\sigma` | $\mu, \sigma$ | 평균, 표준편차 |
| `\Delta`, `\Omega`, `\Sigma` | $\Delta, \Omega, \Sigma$ | 변화량, 공간/영역, 합(Sum) 기호와 다름 |

### 3) 주요 연산자 (Operators)

| 분류 | 명령어 | 기호 | 비고 |
| :--- | :--- | :--- | :--- |
| **합/곱** | `\sum`, `\prod` | $\sum, \prod$ | 아래첨자(`_`), 위첨자(`^`)와 함께 사용 |
| **미적분** | `\int`, `\partial`, `\nabla` | $\int, \partial, \nabla$ | 적분, 편미분, 그래디언트 |
| **관계** | `\approx`, `\equiv`, `\neq` | $\approx, \equiv, \neq$ | 근사, 합동/정의, 같지 않음 |
| **기타** | `\infty`, `\times`, `\cdot` | $\infty, \times, \cdot$ | 무한대, 곱셈 기호(X), 내적(점) |
