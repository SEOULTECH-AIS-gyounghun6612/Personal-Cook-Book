# Zotero 구조 이해 및 관리

## 1. 구조적 특징: 컬렉션(Collection) vs 아이템(Item)

### 1.1 기본 개념

* 컬렉션 (Collection): 아이템을 분류하는 그룹. (파일 시스템의 `폴더`에 해당)
* 아이템 (Item): 개별 논문 및 서지 정보 객체. (파일 시스템의 `파일`에 해당)

### 1.2 객체 분리 구조 (파일 탐색기와 결정적 차이)

일반적인 파일 시스템(Windows 탐색기 등)과 달리, Zotero는 데이터베이스 기반으로 작동함.

* 각각의 아이템은 독립적인 객체 (Independent Object)
  * 모든 아이템은 최상위 저장소인 '내 라이브러리(My Library)'에 `유일한 객체`로 저장됨.
  * 컬렉션은 아이템을 담는 물리적 위치가 아닌, `아이템을 가리키는 '태그(Tag)' 혹은 '바로가기' 개념`.

* 1:N 참조
  * 하나의 아이템(논문)을 여러 컬렉션에 동시에 등록 가능.
  * 예) '논문 A'를 `[연구실]` 컬렉션과 `[졸업논문]` 컬렉션에 동시 배정 가능 (파일 복사가 아닌 참조).
