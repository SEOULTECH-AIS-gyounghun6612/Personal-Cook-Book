# VS Code 기본 환경 설정

## 테마 및 화면 설정

- 색 테마 변경:
  - `Ctrl+K`, `Ctrl+T` 단축키 입력.
  - 목록에서 원하는 테마 선택 (방향키로 미리보기 가능).

- 아이콘 테마 변경:
  - 명령어 팔레트(`Ctrl+Shift+P`) > 'File Icon Theme' 검색.
  - 'Material Icon Theme' 등 확장 프로그램 설치 후 적용 추천.

## 사용자 설정 (Settings)

- 설정 메뉴 진입: `Ctrl + ,` (쉼표).
- 주요 설정 항목:
  - `Font Size`: 글꼴 크기 조절.
  - `Tab Size`: 탭 간격 설정 (보통 4 또는 2).
  - `Word Wrap`: 줄 바꿈 설정 ('on'으로 설정 시 가로 스크롤 방지).
