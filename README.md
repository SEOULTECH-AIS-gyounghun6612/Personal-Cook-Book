# Personal-CookBook

개인 연구 및 개발 효율화를 위한 기술 스택 아카이브입니다.
OS 설정부터 개발 환경, 협업 도구, 논문 작성까지 실무에 필요한 핵심 가이드를 독립적인 서브모듈로 관리합니다.

## Contents

### [Ubuntu System](https://github.com/SEOULTECH-AIS-gyounghun6612/AIS_lab_manual/tree/ubuntu)

Linux 환경 설정 및 시스템 관리

- Install: Ubuntu 설치, 필수 앱 구성, NVIDIA Driver & CUDA/cuDNN 설정.
- File System: 파티션(Partition) 관리, 디스크 마운트(Mount), 디렉토리 명령어.
- Network: 이더넷 설정, SSH 원격 접속, Samba 파일 공유.

### [Virtual Environment](https://github.com/SEOULTECH-AIS-gyounghun6612/AIS_lab_manual/tree/virtual_envirment)

개발 환경 격리 및 배포 관리

- Anaconda: 가상환경 생성/삭제, 패키지 의존성 관리, 환경 변수 설정.
- Docker: 컨테이너(Container) & 이미지(Image) 개념, 라이프사이클 관리, Makefile 기반 워크플로우.

### [VS Code](https://github.com/SEOULTECH-AIS-gyounghun6612/AIS_lab_manual/tree/VS_code)

통합 개발 환경(IDE) 최적화

- Remote Dev: SSH 및 Docker 기반 원격 개발 환경 구축.
- Extensions: 생산성 향상을 위한 필수 확장 프로그램 및 설정 가이드.

### [Python](https://github.com/SEOULTECH-AIS-gyounghun6612/AIS_lab_manual/tree/python)

파이썬 프로그래밍 표준 및 고급 기법

- Convention: Docstring 작성법, 코드 가독성 향상.
- Type Hints: 정적 타이핑(Generic, TypeVar)을 통한 안정성 확보.
- Advanced: Decorator, Dataclass 등 효율적인 코드 구조화 패턴.

### [Git & GitHub](https://github.com/SEOULTECH-AIS-gyounghun6612/AIS_lab_manual/tree/git_with_github)

버전 관리 및 협업 프로세스

- Basics: 브랜치(Branch) 전략, 커밋(Commit) 컨벤션, .gitignore 설정.
- Collaboration: 원격 저장소(Remote) 연동, Push & Pull, PR 워크플로우.
- Advanced: 서브모듈(Submodule) 추가/제거 및 동기화 관리.

### [Paper Workflow](https://github.com/SEOULTECH-AIS-gyounghun6612/Personal-CookBook/tree/paper_workflow)

학술 논문 작성 및 참고문헌 관리

- LaTeX: 논문 템플릿 활용, 구조적 문서 작성법.
- Zotero: 참고문헌(Bibliography) 수집, 관리, BibTeX 연동 및 자동화.
