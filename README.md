# 논문 작성 및 관리 가이드

이 문서는 LaTeX(전문 조판)와 Zotero(서지 관리)를 활용한 효율적인 논문 작성 및 관리 방법을 제안함.

## 1. LaTeX 도입 배경 및 작업 프로세스

기존 워드프로세서(WYSIWYG)의 한계를 극복하기 위해, 내용과 서식을 분리하여 처리하는 컴파일 기반(WYSIWYM) 방식을 채택함.

### [기존 워드프로세서의 한계]

- `양식 변경의 어려움`: 저널 투고 거절 후 타 저널 재투고 시, 인용 스타일과 다단 편집 양식 차이로 인한 전체 재작업.
    ex) IEEE (`[1]`) 에서 APA (`(Author, Year)`)으로 변경, 1단 문서에서 2단 문서로 변경 시 이미지 위치 재조정
- `이미지 배치의 불안정`: 그림 이동 시 문서 전체 레이아웃 붕괴 및 캡션 분리 현상.
- `수식 입력의 비효율`: 마우스 위주의 입력 방식으로 인한 시간 소요 및 심미성 저하.
- `서식 통일성 붕괴`: 수동 조절로 인한 섹션별 스타일 불일치 및 실수 발생.

### [LaTeX 표준 작업 프로세스]

LaTeX는 설정부터 출력까지 명확하게 구분된 단계별 처리를 수행함.

1. `문서 정의 (Preamble)`: 문서 종류, 패키지(수식, 이미지 등) 선언을 통한 뼈대 구축.
2. `본문 작성 (Authoring)`: 논리적 구조 명령어를 이용한 텍스트 작성 및 챕터별 파일 분리 관리.
3. `참고문헌 처리 (Bibliography)`: 외부 `.bib` 연동을 통한 인용 자동화 및 스타일 일괄 변환.
4. `컴파일 및 검토 (Build)`: 엔진(XeLaTeX 등)을 통한 PDF 생성 및 로그 기반 오류 수정.

### LaTeX 도입 효과

- `내용과 서식의 분리`: 저자는 논리적 구조(섹션, 수식) 작성에 집중, 스타일은 클래스 파일이 전담.
- `알고리즘 기반 조판`: 수식, 자간, 단어 나눔(Hyphenation), 이미지 배치를 최적의 알고리즘으로 자동 처리.
- `텍스트 기반 관리`: 소스 코드(.tex) 형태이므로 Git을 통한 변경 이력 추적 및 협업 용이.

상세 가이드 -> [LaTeX 가이드](./LaTeX/README.md)

## 2. Zotero 및 LATTE 연동 워크플로우

연구실 표준 템플릿(LATTE)과 서지 관리 도구(Zotero)를 결합하여 반복 작업을 자동화함.

### [Zotero: 서지 데이터 관리 자동화]

수동 관리의 치명적 오류(인용 키 충돌, 메타데이터 오타, PDF 분실)를 시스템으로 해결.

- Bib 자동화: [Better BibTeX] 확장을 통한 고유 인용 키 생성 및 `.bib` 파일 실시간 동기화.
- 통합 관리: 브라우저 확장을 통한 원클릭 수집 및 PDF/메모 일원화.
- 상세 가이드: [Zotero 가이드](./Zotero/README.md)

### [LATTE: 연구실 표준 템플릿 활용]

- 즉시 작성: 미리 정의된 스타일(`thesis`, `neurips`)과 매크로를 활용하여 설정 시간 단축.
- Git 기반 관리:
    - 통합 관리: 메인 리포지토리(`paper_bag`)에서 모든 논문을 서브모듈로 관리.
    - 독립 격리: 각 논문은 `orphan branch`로 생성하여 이력 섞임 방지.
- 상세 가이드: [LATTE 템플릿](./LATTE/README.md)
