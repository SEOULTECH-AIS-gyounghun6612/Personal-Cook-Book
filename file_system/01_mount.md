## mount

<center>

| 명령어 | 역할                                                                                          |
| :----: | :-------------------------------------------------------------------------------------------- |
| m      | 기초적인 명령어 정보를 출력                                                                   |
| n      | 새로운 파티션을 추가. 파티션이 없을 경우 1, 마지막 파티션 번호 보다 1 큰값을 기본값으로 사용. |
| d      | 지정된 번호의 파티션을 제거. 단일 파티션만 존재 할 경우 해당 파티션을 자동 삭제.              |
| g      | 현재 테이블을 gpt 파티션 테이블로 변경. (2.2Tb 이상의 용량을 단일 파티션으로 구성 할 때 사용) |
| w      | 현재까지 작성된 파티션 변경 사항을 저장                                                       |
