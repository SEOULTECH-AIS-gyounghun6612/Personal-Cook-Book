# Docker 이미지 (Docker Image)

## 개요

- **정의**: 애플리케이션 실행에 필요한 모든 환경을 포함한 읽기 전용(Read-only) 패키지.
- **구성 요소**: 소스 코드, 런타임, 라이브러리, 환경 변수, 설정 파일.

## 주요 특징

- **계층 구조 (Layered Structure)**:
  - Dockerfile의 각 명령어가 독립적인 레이어로 생성.
  - 동일 레이어 공유 및 재사용을 통해 저장 공간 및 빌드 속도 최적화.
- **불변성 (Immutability)**:
  - 한 번 생성된 이미지는 상태가 변하지 않음.
  - 개발, 테스트, 운영 환경에서의 일관성 및 재현성 보장.

## 이미지와 컨테이너의 관계

- **설계도와 실체**:
  - **이미지**: 실행을 위한 정적인 템플릿 (붕어빵 틀).
  - **컨테이너**: 이미지를 실행한 동적인 인스턴스 (붕어빵).
- **레이어 결합**:
  - 이미지는 여러 개의 읽기 전용(Read-only) 레이어로 구성.
  - 컨테이너 실행 시 이미지 위에 얇은 **쓰기 가능(Writable) 레이어**가 추가됨.
  - 컨테이너 내부의 모든 변경 사항은 이 쓰기 가능 레이어에 기록되며, 원본 이미지는 수정되지 않음.
- **생명 주기**:
  - 하나의 이미지로부터 여러 개의 독립적인 컨테이너 생성 가능.
  - 컨테이너 삭제 시 쓰기 레이어의 데이터는 사라지지만, 이미지는 그대로 유지됨.
