# Docker 이미지 (Docker Image)

애플리케이션 실행에 필요한 모든 환경을 포함한 읽기 전용(Read-only) 패키지

## 목차

1. [개요 및 특징 (Overview)](#1-개요-및-특징-overview)
2. [이미지와 컨테이너 (Relationship)](#2-이미지와-컨테이너-relationship)

## 1. 개요 및 특징 (Overview)

소스 코드, 런타임, 라이브러리, 환경 변수 등 실행에 필요한 모든 요소를 포함

### 주요 특징

* 불변성 (Immutability): 한 번 생성되면 내용이 변하지 않음. 배포 환경의 일관성 보장.
* 계층 구조 (Layered): `Dockerfile`의 각 명령어가 하나의 레이어가 되며, 이를 쌓아 올려 구성. (저장 효율성 증대)

## 2. 이미지와 컨테이너 (Relationship)

이미지는 설계도(Class), 컨테이너는 실체(Instance)

### 구조적 차이

1. 이미지 (Image)
  * 읽기 전용(Read-only) 레이어들의 집합
  * 수정 불가능 (수정 시 새로운 이미지 생성 필요)

2. 컨테이너 (Container)
  * 이미지 위에 쓰기 가능(Writable) 레이어가 한 장 얹혀진 상태
  * 실행 중 발생하는 모든 데이터 변경은 이 얇은 레이어에만 기록됨
  * 컨테이너가 삭제되면 쓰기 레이어는 소멸하지만, 원본 이미지는 영향받지 않음
