# Docker 컨테이너란 무엇인가?

Docker 컨테이너는 애플리케이션과 해당 애플리케이션을 실행하는 데 필요한 모든 종속성(라이브러리, 시스템 도구, 코드, 런타임 등)을 함께 묶는 경량의 독립 실행형 실행 가능한 패키지입니다.

## 주요 특징

*   **격리성**: 컨테이너는 호스트 시스템 및 다른 컨테이너로부터 격리되어 실행됩니다.
*   **이식성**: 컨테이너는 어떤 환경(개발, 테스트, 프로덕션)에서든 동일하게 실행될 수 있습니다.
*   **경량성**: 가상 머신과 달리 컨테이너는 호스트 운영 체제의 커널을 공유하므로 오버헤드가 적습니다.
*   **효율성**: 컨테이너는 빠르게 시작하고 중지할 수 있으며, 리소스 사용이 효율적입니다.

요약하자면, Docker 컨테이너는 애플리케이션을 안정적이고 일관된 환경에서 실행할 수 있도록 패키징하는 표준화된 방법입니다.
