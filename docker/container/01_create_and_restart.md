# Docker 컨테이너 생성 및 재시작

이 문서는 Docker 컨테이너를 생성하고 재시작하는 기본적인 명령어와 옵션을 설명합니다.

## 컨테이너 생성 (`docker run`)

`docker run` 명령어는 Docker 이미지로부터 새로운 컨테이너를 생성하고 시작합니다.

기본적인 구문은 `docker run [OPTIONS] IMAGE [COMMAND] [ARG...]` 입니다.

### 주요 옵션

*   `-d` 또는 `--detach`: 컨테이너를 백그라운드에서 실행합니다.
*   `--name <이름>`: 컨테이너에 사용자 정의 이름을 할당합니다.
*   `-p <호스트_포트>:<컨테이너_포트>` 또는 `--publish`: 호스트 머신의 포트를 컨테이너 내부의 포트와 매핑합니다.
*   `-v <호스트_경로>:<컨테이너_경로>` 또는 `--volume`: 호스트 머신의 볼륨(디렉토리 또는 파일)을 컨테이너에 마운트합니다.
*   `-e <키>=<값>` 또는 `--env`: 컨테이너 내부에 환경 변수를 설정합니다.
*   `-it` 또는 `--interactive --tty`: 컨테이너를 대화형 모드로 실행하고 의사 TTY를 할당하여 명령줄을 통해 컨테이너와 상호 작용할 수 있도록 합니다.
*   `--rm`: 컨테이너가 종료될 때 자동으로 제거합니다.
*   `--restart <정책>`: 컨테이너의 재시작 정책을 설정합니다 (예: `always`, `on-failure`, `unless-stopped`, `no`).
*   `--entrypoint <명령>`: Docker 이미지에 지정된 기본 진입점 명령을 재정의합니다.
*   `--network <네트워크_이름>`: 컨테이너를 특정 Docker 네트워크에 연결합니다.

## 컨테이너 재시작 (`docker restart`)

`docker restart` 명령어는 하나 이상의 실행 중인 컨테이너를 재시작합니다.

`docker restart`를 실행하면 Docker는 먼저 컨테이너에 `SIGTERM` 신호를 보내 정상적으로 종료하도록 요청합니다. 기본 시간 초과(일반적으로 10초) 내에 컨테이너가 중지되지 않으면 Docker는 `SIGKILL` 신호를 보내 강제로 종료한 다음 컨테이너를 다시 시작합니다.

### 사용법

```bash
docker restart <컨테이너_이름_또는_ID>
```

여러 컨테이너를 재시작하려면 이름이나 ID를 나열하면 됩니다.

```bash
docker restart <컨테이너1> <컨테이너2>
```

### 관련 명령어

*   `docker stop <컨테이너_이름_또는_ID>`: 실행 중인 컨테이너를 중지합니다.
*   `docker start <컨테이너_이름_또는_ID>`: 중지된 컨테이너를 시작합니다.

## 실행 중인 컨테이너에 명령어 실행 (`docker exec`)

`docker exec` 명령어는 실행 중인 Docker 컨테이너 내부에서 명령을 실행하는 데 사용됩니다. 컨테이너를 중지하고 다시 시작할 필요 없이 컨테이너의 운영 체제 및 프로세스와 상호 작용할 수 있습니다.

### 목적

*   **디버깅:** 컨테이너 내부에서 진단 명령(예: `ls`, `ps`, `top`)을 실행하여 상태를 검사합니다.
*   **대화형 셸:** 실행 중인 컨테이너 내에서 대화형 셸(예: `bash`, `sh`)을 열어 수동으로 작업을 수행합니다.
*   **유틸리티 실행:** 컨테이너 내부에 있는 특정 유틸리티나 스크립트를 실행합니다.

### 기본 구문

```bash
docker exec [OPTIONS] CONTAINER COMMAND [ARG...]
```

*   `[OPTIONS]`: 명령어의 동작을 수정하는 선택적 플래그입니다.
*   `CONTAINER`: 명령을 실행하려는 실행 중인 컨테이너의 이름 또는 ID입니다.
*   `COMMAND`: 컨테이너 내부에서 실행하려는 명령어입니다.
*   `[ARG...]`: `COMMAND`에 대한 모든 인수입니다.

### 주요 옵션

*   `-i`, `--interactive`: 연결되어 있지 않아도 STDIN을 열린 상태로 유지합니다. 셸과 같은 대화형 명령어에 중요합니다.
*   `-t`, `--tty`: 의사 TTY를 할당합니다. 출력을 올바르게 표시하기 위해 대화형 셸에도 필수적입니다.
*   `-d`, `--detach`: 분리 모드(백그라운드)에서 명령을 실행합니다.
*   `-u`, `--user`: 명령을 실행할 사용자 이름 또는 UID를 지정합니다.
*   `-w`, `--workdir`: 컨테이너 내부의 작업 디렉토리를 설정합니다.

### 예제

1.  **컨테이너에서 대화형 Bash 셸 열기:**
    ```bash
    docker exec -it my_container_name bash
    ```
    (이것은 컨테이너에 "로그인"할 수 있도록 하는 가장 일반적인 사용 사례입니다.)

2.  **컨테이너 내부의 특정 디렉토리에 있는 파일 나열:**
    ```bash
    docker exec my_container_name ls -l /app
    ```
