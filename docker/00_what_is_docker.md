# Docker란 무엇인가?

## 개요

애플리케이션의 개발, 배포, 실행을 위한 오픈 소스 플랫폼.

## 핵심 개념

### 1. Docker

* **정의**: 리눅스 컨테이너 기술(LXC)을 기반으로 한 가상화 플랫폼.
* **목적**: 개발 환경과 운영 환경의 불일치 해소 ("Build Once, Run Anywhere").
* **구조**: 클라이언트-서버 아키텍처 (Docker Client <-> Docker Daemon).

### 2. [Container](container/00_what_is_container.md)

* **정의**: 애플리케이션과 모든 종속성(Library, Runtime 등)을 패키징한 격리된 실행 인스턴스.
* **특징**:
  * **경량성**: 호스트 OS 커널을 공유하여 VM보다 훨씬 가볍고 빠름.
  * **격리성**: 각 컨테이너는 독립된 파일 시스템과 네트워크 환경을 가짐.
* **상세 보기**: [컨테이너 개요 및 명령어](container/)

### 3. [Image](image/00_what_is_image.md)

* **정의**: 컨테이너를 생성하기 위한 읽기 전용(Read-only) 템플릿(설계도).
* **특징**:
  * **불변성**: 한 번 생성되면 변하지 않음 (상태 저장은 컨테이너 계층에서 수행).
  * **계층 구조**: 여러 레이어(Layer)가 쌓여 하나의 이미지를 구성 (저장 효율성).
* **상세 보기**: [이미지 개요 및 빌드](image/)
