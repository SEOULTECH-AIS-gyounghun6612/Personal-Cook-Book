## 1. 패키지 설치 (Install)

Conda 채널을 통해 검증된 패키지 설치

### 설치 명령어

```bash
conda install {package_name}
```

* 버전 지정: `conda install numpy=1.21`
* 채널 지정: `conda install -c conda-forge {package_name}` (기본 채널에 없을 경우)
* 여러 패키지: `conda install numpy pandas matplotlib`

## 2. 패키지 관리 (Manage)

현재 환경에 설치된 패키지 상태 확인 및 제어

### 주요 명령어

| 동작      | 명령어                    | 설명                                              |
| :---      | :---                      | :---                                              |
| 검색      | `conda search {text}`     | 설치 가능한 패키지 및 버전 검색                   |
| 목록      | `conda list`              | 현재 환경에 설치된 모든 패키지 조회               |
| 갱신      | `conda update {package}`  | 특정 패키지를 최신 버전으로 업데이트              |
| 전체 갱신 | `conda update --all`      | 현재 환경의 모든 패키지 업데이트                  |
| 삭제      | `conda remove {package}`  | 특정 패키지 삭제                                  |
| 캐시 삭제 | `conda clean --all`       | 다운로드된 캐시 및 미사용 패키지 정리 (용량 확보) |

## 3. Pip과 혼용 (Pip Interoperability)

Conda에 없는 패키지는 `pip`을 사용하여 설치 가능

### 사용 시 주의사항

가급적 `conda install`을 우선 사용하고, 없을 경우에만 `pip install` 사용 권장 (의존성 충돌 방지)

```bash
# 가상환경 활성화 후 pip 사용
conda activate {env_name}
pip install {package_name}
```
